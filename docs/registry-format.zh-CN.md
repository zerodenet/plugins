# 统一市场契约

[English](registry-format.md) · **简体中文**

## 产品登记

`catalogs/plugins.json` 为 schema-v3 唯一维护目录。自动化从公开固定发行资产取得完整原始资料，技术校验后自动登记，不进行人工准入审核。稳定产品 ID、发布者公钥、仓库、发行源及宿主/包 ID 标识来源；名称、简介和链接原样登记。

`surfaces` 和 `capabilities` 是声明，不是市场权限上限或授权。新版本声明不需要更新登记。市场只校验唯一标识数组的结构，不维护固定界面白名单；宿主决定支持的 API 和界面。`withdrawn: true` 表示显式撤回，既有身份不能静默重新分配。

[JSON schemas](../schemas/) 描述结构；`scripts/marketplace_schema.py` 另校验身份、命名空间、迁移和固定资产位置。`catalogs/zboard.json` 和 `catalogs/znet-sink.json` 为自动生成的 schema-v2 兼容投影，不独立编辑。

## 发布者发行清单

每个 GitHub Release 提供 schema-v1 `marketplace-entry.json`：产品/仓库/发布者身份、源码标签与完整提交、版本/频道/时间/说明及宿主目标。目标包含稳定包 ID、宿主版本范围、该版本的界面/能力，以及具有系统、架构、大小、SHA-256 和签名信息的固定资产。来源和包身份保持一致；权限不要求是首次登记的子集。

生成器读取签名 `.zbplugin` 和 `.zspkg`，不执行它们。宿主独立验签，并按自身策略展示权限、要求用户确认和执行授权。

## 派生快照

schema-v1 快照组合当前登记、最多 20 条发布动态和有效的目标版本。仅目标 `releases` 用于安装选择；扩大权限的版本仍可被发现。目标级声明数组汇总登记与可发现版本声明的并集，兼容旧消费端；它们不能授权所选安装包。版本级声明保持原样。

快照与六个宿主/频道静态接口共享内容摘要。来源不可用时保留上次可用版本并标记陈旧；显式撤回优先。生成快照、安装包和站点不进入 Git。
