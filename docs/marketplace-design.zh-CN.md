# 统一插件市场架构

[English](marketplace-design.md) · **简体中文**

用户发现的是一个插件产品；产品显式声明一个或多个宿主目标，市场绝不根据 IP、Referer 或 User-Agent 猜宿主。

| 层次 | 归属 | 持久内容 |
| --- | --- | --- |
| 产品注册 | 中央市场 | 产品 ID、发布者原始资料、仓库、可信发布者、发行源、宿主/包身份、已审核上限、撤回 |
| 发布清单 | 作者仓库 | 版本/渠道、源码提交、目标包、宿主/平台兼容、大小、摘要、签名、发行说明 |
| 构建快照 | 市场构建 | 网站展示的作者发布记录、宿主使用的已校验发行、新鲜度、快照版本 |
| 安装生命周期 | 各宿主 | 最终下载、签名/策略校验、授权、安装、升级、回滚、停用、卸载、审计 |

Astro 站点与静态 API 来自同一次构建：GitHub Actions 有界汇总作者发行，GitHub Pages 原子发布预渲染列表、详情、完整快照、按宿主/频道拆分的 JSON 和 schema。宿主版本、系统与架构由 ZBoard 和 ZNet Sink 在本地过滤。首期无需数据库、Worker 或访客 GitHub token；只有未来出现鉴权写入、个性化或确需服务端检索时才引入动态服务。

站点沿用 Minted Directory Astro 的静态 JSON 目录思路。Ever Works 只影响产品卡片、详情信息层级和发布者/目标呈现；视觉采用常规产品站的白色、浅灰与深灰基础色，以低饱和蓝色表达主操作，以绿色和琥珀色区分稳定与预发布状态，并跟随系统浅色或暗黑模式。详情页展示开发者主页、文档、安全与反馈渠道，并区分作者发布动态和可安装的已验证发行。首期只预留评分与评价版位，不展示虚构分数；账号、评论写入、收藏、支付与管理后台不在首期范围。

发布者提交的名称、简介、分类和链接始终原样展示。`surfaces` 与 `capabilities` 是宿主协议 key，不属于产品文案；详情页可从宿主维护的标准字典显示可读说明，但必须同时显示原 key，未知 key 不推断含义。字典不得包含产品 ID 或插件专属覆盖。

迁移期旧 schema-v2 宿主目录是确定性投影，绝不作为第二份人工来源。只有受支持的 ZBoard 与 ZNet Sink 版本都改用统一静态 API，且兼容窗口结束后，才能移除这些投影。
