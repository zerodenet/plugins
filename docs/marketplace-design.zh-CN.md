# 共享插件市场架构

[English](marketplace-design.md) · **简体中文**

## 定位

插件市场是精选登记目录，也是宿主提供便捷管理的入口。ZBoard、ZNet Sink 及未来宿主可在线浏览已准入插件，使用者可以快速了解、获取、安装和管理插件，而无需把开发者自己的发行历史复制进中心仓库。

市场准入表示宿主团队审核了插件立意和稳定信任边界，不代表每个软件版本都要重复排队审批。

## 责任归属

| 组件 | 负责内容 |
| --- | --- |
| 市场目录 | 准入、身份、仓库、发布者公钥、资料/发行源入口、宿主范围、能力与界面上限、撤回 |
| 插件仓库 | 基础资料、源码、正式版/RC/Dev 生命周期、不可变发行元数据、安装包、摘要、兼容声明和更新说明 |
| 宿主 | 浏览搜索、发行发现、频道与精确版本选择、签名及策略校验、安装升级降级卸载、本地状态和审计 |
| 离线导入 | 开发自测、私有分发、本地 DIY，以及管理员明确授权的非市场插件 |

## 在线流程

1. 宿主读取所属市场目录，再从每个插件仓库的 `marketplace.json` 读取基础资料。
2. 进入插件详情时，宿主通过登记的发行源适配器读取公开版本及发布说明。
3. 宿主识别符合规范的正式版、RC 与 Dev 标签，并读取所选版本的固定元数据。
4. 宿主校验仓库与插件身份、登记的发布者公钥、能力及界面上限、目标平台、包摘要、包签名和宿主兼容性。
5. 管理员安装、升级、降级或固定精确版本。正式版为默认频道，RC 与 Dev 由管理员主动选择。

版本可被发现不等于获得授权。仓库发行只有符合登记的适配器才会展示；签名包只有保持在准入边界内才可安装。

## 更新与撤回

常规插件发行和基础资料调整永远不修改市场目录。仓库迁移、发布者或密钥轮换、资料或发行源契约变更、新增宿主或扩大能力与界面范围时才重新审核。市场目录也负责暂停和撤回信号，宿主决定这些信号对已安装实例及离线运行的影响。

首个发行源适配器使用 GitHub Releases，每个发行包含一个 marketplace-entry.json。未来可以扩展其他适配器，但不能重新把市场变成版本台账。
