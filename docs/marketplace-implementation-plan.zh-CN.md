# 统一插件市场实施计划

[English](marketplace-implementation-plan.md) · **简体中文**

状态：实施中。技术选择：Astro + Minted Directory Astro；参考 Ever Works 的列表与详情信息层级。迁移结束前，现有宿主目录继续作为自动生成的兼容投影。

## 目标与边界

- 一个统一市场入口；网站支持搜索、筛选、详情和已验证产物链接。
- ZBoard 与 ZNet Sink 读取同一版本的宿主/频道静态文件，路径显式包含 `zboard` 或 `znet-sink`，不从 IP、Referer 或 User-Agent 猜测宿主。
- 中央只登记稳定产品身份、可信发布者、仓库与能力上限；作者仓库发布一个可包含多个宿主目标的生成清单。
- 快照构建只读取、校验、过滤和发布元数据，不构建或执行第三方包。
- 安装、更新、验包、授权、运行、回滚和卸载都由宿主负责。
- 首期不做账号、评论、收藏、评分、支付、安装量和管理后台。

## 数据与服务契约

数据分为三层：schema-v3 产品注册、schema-v1 作者发布清单和 schema-v1 派生快照。注册保存稳定产品 ID 与各宿主不可静默改写的包 ID；发布清单保存版本/频道、源提交、宿主兼容范围、平台、地址、大小、摘要和签名；快照将两者合并给网站与宿主查询。目录来源信任不能替代宿主验包，也不能由作者提交的新密钥自动提升。

`GET /api/plugins.json` 提供网站发现使用的完整快照；`GET /api/plugins/{host}/{channel}.json` 提供按 ZBoard/ZNet Sink 与 Stable/RC/Dev 在构建期拆分的候选发行。宿主在本地按 `host_version`、`os` 与 `arch` 严格筛选，不借用另一宿主或不兼容平台的产物。源码已登记但无已验证产物时只出现在完整快照，不进入宿主频道文件。

Astro 页面和静态 JSON API 使用同一次快照结果，由 Cloudflare Pages 发布根路径正式站点，并由 GitHub Pages 保留仓库路径备用站点；两者都包含页面、快照、宿主/频道文件和 schema。首发不依赖 Cloudflare Worker。GitHub 凭据只在构建环境；在线浏览不逐项访问作者仓库。临时上游故障保留并标记最后可用发行，显式撤回始终优先。未来只有在出现鉴权写入、个性化或确需服务端检索时才考虑动态服务。

## 阶段与验收

### P0 基线

隔离既有脏工作树；核实现行登记、真实发行、两端消费路径与身份映射；固定 Minted/Ever 参考提交和许可。验收：迁移矩阵、依赖清单与可运行基线。

### P1 注册与发布契约

建立版本化 schema、单/双宿主目标、不可变身份与迁移校验；更新 Issue 入驻和审核。验收：正常样例通过，重复身份、错宿主、密钥替换、越权元数据失败。

### P2 工具与示例

从真实签名包读取身份并计算摘要/大小，生成同一 Release 的清单；中央不复制 runtime/SDK、不执行包、不保存私钥。验收：单/双目标 fixture 和篡改负例覆盖。

### P3 快照与查询

有边界地读取作者发行，分别记录网站可展示的正式版/预发布动态和宿主可安装的已验证发行，构建统一快照与宿主/频道静态 API；客户端覆盖版本/平台过滤，发布流程覆盖缓存、失败回退与撤回。验收：不同宿主只得到自身已验证产物，网站仍能尊重并展示作者公开发布记录，API 与网站语义一致。

### P4 网站与公开服务

提供搜索、宿主/分类筛选、产品卡片、详情、开发者登记资料与已提交外部链接、完整发布记录、surfaces/capabilities 原 key 与宿主标准说明、评分/评价预留位及站内提交插件流程；没有已验证产物时不显示安装入口。安装信任、发布审核、市场数据、安全和职责边界统一在 `docs.zerodenet.org/marketplace/` 维护，市场站只提供明确入口，不复制第二份公开文档。产品字段只显示 Issue/发行清单经 Action 登记的原值，不翻译、不改写、不推断链接；宿主协议说明与产品资料分离，未知 key 不推断。GitHub 保留最终身份确认、Issue、审计历史和源文件，不作为用户理解公开流程的前置入口。验收：真实登记产品与明确测试 fixture 分离，桌面及移动端完整可读。

### P5 宿主迁移

两端读取显式宿主/频道文件，在本地按版本、系统和架构选择产物，继续独立验包和授权。旧目录只从统一登记生成，并设置退出条件。验收：真实签名包的安装、升级和数据保留按宿主完成；没有双端真实包时不宣称双端验收。

### P6 部署

配置定时/登记变化触发、Cloudflare Pages 正式发布与 GitHub Pages 备用发布，验收根路径和仓库路径下的线上搜索、详情、完整快照、六个宿主/频道 API 文件与 schema；把 `plugins.zerodenet.org` 绑定到 `zero-plugins` 项目。验收双宿主本地兼容筛选、缓存刷新、上游故障和回滚。各阶段分开记录本地代码、提交、推送、部署及真实安装证据。

实施证据与尚未完成的发布边界见[实施状态](marketplace-implementation-status.zh-CN.md)。
