# 安装与信任

[English](usage.md) · **简体中文**

从所属宿主源目录选择插件并阅读插件仓库文档。安装前核实宿主/API 兼容范围、目标平台、所需能力与发布者归属。没有发行记录的源码条目不能安装。

对于 ZBoard，通过可信渠道获得发布者公钥并配置宿主信任。从发布者下载对应平台的签名 `.zbplugin`，对照发行元数据核对 SHA-256，再使用插件管理的离线导入。安装、配置、启停、升级与移除均由 ZBoard 验证和控制。具体操作见插件自己的安装指南。

本仓库的源目录是未签名的编辑记录，不能作为 `plugins.catalog_url`。在线安装需要单独发布的宿主签名目录和宿主支持的下载地址。当前分发限制见[发布指南](publishing.zh-CN.md)。

目录及安装包签名证明来源和完整性，不授予权限，也不能使任意原生代码自动变得安全。ZBoard 原生插件是受信子进程，不是操作系统沙箱；授予信任前应审核发布者和能力申请。

账户及注册策略、凭据与节点配置发布由 ZBoard 核心掌管。禁用或卸载 OAuth 不会把用户记录所有权交给插件。数据保留与迁移由宿主生命周期控制。ZNet Sink 的宿主运行时和安装契约仍在开发，空客户端目录不代表已有可用插件运行时。
