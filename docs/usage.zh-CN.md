# 插件选择与运维

[English](usage.md) · **简体中文**

## 选择宿主

插件安装到特定应用中。先选择宿主集合，再确认插件支持的宿主/API 版本和操作系统。安装包供应状态与配置说明在对应集合中维护。

- [ZBoard 安装与运维](https://github.com/zerodenet/plugins/blob/zboard/docs/usage.zh-CN.md)
- [ZNet Sink 接入状态](https://github.com/zerodenet/plugins/blob/znet-sink/README.zh-CN.md)

公共市场已列入规划。在签名目录和发行版本提供前，开发包按宿主分支中的构建说明使用。

## 安装与信任

宿主管理员选择可信发布者。安装前，宿主验证包来源、完整性、兼容性和所需能力；在线与离线安装应执行相同的宿主契约。

配置、启用、停用和升级通过宿主应用管理。提供方凭据及外部服务登记要求见对应插件的配置指南。

## 数据与升级

宿主负责插件私有存储、迁移和保留策略。升级前按照宿主要求备份，并检查新版本的兼容条件。移除插件不会删除账户或已完成事务等核心业务记录。

卸载和数据清理的准确行为以宿主运维指南为准。报告问题时注明宿主、插件版本、平台和脱敏复现步骤。
