# 安装与运维

[English](usage.md) · **简体中文**

本指南适用于安装到 ZBoard 的插件。各插件的宿主配置要求见对应说明。ZNet Sink 的插件运行时提供后，将补充客户端安装指南。

## 安装要求

选择与宿主应用、宿主 API 版本、操作系统和 CPU 架构匹配的包。`admin` 等页面声明表示界面出现的位置；宿主操作权限由能力和宿主策略另行判断。

管理员在 ZBoard 中配置可信发布者公钥。安装前应从发布者的可信渠道获取公钥。本地测试所需的开发包和密钥生成方式见[开发指南](development.zh-CN.md)。

## 安装插件包

1. 将发布者公钥加入宿主配置的 `plugins.trusted_publishers`，修改此配置后重启宿主。
2. 打开 ZBoard 插件管理页面，选择离线导入。
3. 选择签名 `.zbplugin` 文件并确认导入。ZBoard 校验后安装，初始状态为停用。
4. 打开插件配置页，保存必要设置，并运行配置检测。
5. 启用插件，在对应的用户界面验证功能。

安装、配置、启用和停用均为动态操作，无需重启宿主。配置检测可能只校验参数或提供方元数据；认证插件还需要用真实账户验证完整登录流程。

### 在线安装

配置签名目录后，管理员可从宿主市场页面选择插件。`plugins.catalog_url` 应指向目录文档，在线安装与离线导入执行相同的包校验。公共分发进度见[项目 README](../README.zh-CN.md)。

## 升级与恢复

升级前，一并备份宿主数据库、插件目录和加密密钥。导入同一插件的新版本会触发宿主升级流程，发布者必须与已有安装一致。

ZBoard 在提交变更前准备候选配置、私有数据和运行时。升级成功后保留原启停状态；准备失败则保留旧版本和已提交数据。新包未声明测试过当前宿主版本时，需要先停用插件再升级。

恢复保留版本时，先停用插件，再在详情页选择目标版本。宿主会检查配置与数据兼容性，恢复旧二进制不会执行向下数据迁移。

## 停用、卸载与数据清理

| 操作 | ZBoard 中的结果 |
| --- | --- |
| 停用 | 停止运行时并撤销插件页面与调用会话，保留安装和数据。 |
| 卸载 | 停止插件并移除程序与页面，保留配置、私有数据和操作记录。 |
| 清除保留数据 | 卸载后可用，由宿主清除插件配置与私有数据。 |

账户、身份绑定、订单和凭证等核心记录由 ZBoard 管理。移除插件不会删除这些记录，也不会撤销已完成的业务事务。

## 问题排查

| 现象 | 检查内容 |
| --- | --- |
| 市场为空 | 是否已配置目录，以及目录是否可访问、签名有效且未过期。 |
| 导入被拒绝 | 发布者信任、包摘要、宿主/API 兼容性和目标平台。 |
| 插件启动失败 | 插件操作记录、宿主日志、配置和平台执行策略。 |
| 配置无法保存 | 遇到版本冲突后刷新，再重新应用预期修改。 |

OAuth 相关问题见[配置参考](../zboard/oauth/docs/configuration.zh-CN.md)。[报告问题](../CONTRIBUTING.zh-CN.md)时请提供插件与宿主版本，以及脱敏日志。
