# 安装与信任

[English](usage.md) · **简体中文**

从宿主插件市场选择已准入插件。名称、说明、许可证、作者/维护者和文档链接来自插件中心入驻资料；版本列表、发布时间和发布说明来自该仓库的 Releases。宿主允许管理员选择正式版、RC、Dev 或精确版本，并在安装前按登记的发布者公钥及能力上限校验所选安装包。

能在线发现不等于可以直接安装。宿主还会校验插件身份、版本、平台、包摘要和签名、宿主/API 兼容性及申请能力。正式版是默认频道，RC 和 Dev 必须由管理员主动选择。

离线导入不依赖市场准入，继续用于开发自测、私有分发、本地 DIY 及非市场插件。管理员明确确认来源和签名身份，宿主仍执行相同的安装包、兼容性和生命周期校验。

账户、注册策略、凭据、订单、节点发布及已提交业务记录由 ZBoard 核心拥有。插件负责自己的集成逻辑和注入界面；安装或移除插件不会改变核心数据归属。
