ZBOARD · OAUTH / OIDC

OAuth 提供方

配置 OIDC 身份提供方，由 ZBoard 核心完成账号绑定和会话签发。

第三方账号登录 ZBoard

配置并启用插件后，登录页会显示第三方登录入口。首次使用请先通过邮箱登录，在“账户安全”中确认密码并绑定第三方账号。

正在连接宿主…
填写提供方公布的精确 Issuer，路径和末尾斜杠应保持一致。仅支持公网 HTTPS。

在提供方登记精确回调地址：你的站点地址/api/v1/auth/oidc/callback。站点地址使用 ZBoard 的公开访问地址，生产环境必须为 HTTPS。

由宿主加密保存，授权码交换时仅发送到已配置提供方的 Token 端点；元数据检测不发送密钥。 以空格分隔，必须包含 openid。

检测通过仅表示元数据符合本插件要求，不代表 Client ID / Secret 有效，也不代表登录链路已打通。停用插件后，本页会话由宿主撤销。
